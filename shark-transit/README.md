# ШАРК ТРАНЗИТ — макет главной страницы

Адаптивный HTML-макет главной страницы сайта грузоперевозок по дизайну
первого экрана и прототипу.

## Как посмотреть

Открыть `index.html` в браузере — сборка не требуется. Для корректной
загрузки шрифтов (Manrope, Montserrat с Google Fonts) нужен интернет;
без сети макет работает на системных шрифтах.

## Структура страницы (по прототипу)

1. Прелоадер с логотипом (референс — tlk-group.ru)
2. Шапка: меню, телефон, кнопка «Нужна срочная доставка»
3. Первый экран: слоган, диагональная панель с фурой, карточка цифр
   (13+ лет, 0 убытков, страхование до 10 млн ₽, отсрочка до 30 дней)
4. Услуги: тентовые и рефрижераторные перевозки + доп. услуги
5. Калькулятор стоимости (демо-расчет на JS)
6. Лента клиентов «300+ компаний» (бегущая строка)
7. Преимущества — 6 карточек
8. Основные направления с картой и ценами + форма «свой маршрут»
9. Этапы перевозки — 5 шагов с прогресс-линией
10. Кейсы на темном фоне
11. О компании
12. Отзывы
13. FAQ-аккордеон
14. CTA-форма заявки
15. Контакты и футер

## Анимации (референсы — terminal-industries.com, elittrans62.ru)

- появление блоков при скролле (IntersectionObserver);
- въезжающая фура с вращающимися колесами и «дорогой» на первом экране;
- счетчики цифр, прогресс линии этапов, бегущая строка клиентов;
- параллакс фуры при скролле, hover-эффекты карточек;
- уважение `prefers-reduced-motion`.

## Файлы

- `index.html` — разметка (вся графика — инлайновый SVG, без внешних картинок)
- `css/style.css` — стили, брейкпоинты: 1100 / 860 / 560 px
- `js/main.js` — прелоадер, меню, анимации, демо-калькулятор, формы

Формы и калькулятор работают в демо-режиме (без бэкенда): подмените
обработчики в `js/main.js` на реальные запросы при интеграции.
