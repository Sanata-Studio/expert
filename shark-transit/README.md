# ШАРК ТРАНЗИТ — макет главной страницы

Адаптивный HTML-макет главной страницы сайта грузоперевозок по дизайну
первого экрана и прототипу.

## Как посмотреть

Открыть `index.html` в браузере — сборка не требуется. Для корректной
загрузки шрифтов (Manrope, Montserrat, JetBrains Mono с Google Fonts)
нужен интернет; без сети макет работает на системных шрифтах.

## Дизайн-система

- **Логотип** — чистый знак акулы с линиями скорости + вордмарк
  (без пиктограммы грузовика).
- **Типографика** — Montserrat ExtraBold для крупных заголовков,
  Manrope для текста, JetBrains Mono для служебных надписей: индексы
  секций (01–10), теги, метаданные маршрутов, подписи.
- **Современные приемы**: bento-сетка преимуществ, интерактивные
  строки услуг и маршрутов с заливкой по ховеру, контурные цифры
  (-webkit-text-stroke), наклонная бегущая строка, зерно на темных
  секциях, гигантский контурный вордмарк в футере, прогресс-бар
  скролла, автоскрытие шапки при скролле вниз.

## Структура страницы (по прототипу)

1. Прелоадер с акулой и процентами загрузки (референс — tlk-group.ru)
2. Шапка: меню с индексами, телефон, кнопка «Срочная доставка»
3. Первый экран: слоган, диагональная панель с фурой, полоса цифр
   (13+ лет, 0 убытков, страхование до 10 млн ₽, отсрочка до 30 дней)
4. Наклонный тикер «Точность · Надежность · Результат»
5. 01 Услуги — интерактивные строки (тент / реф / сопровождение)
6. 02 Калькулятор стоимости (демо-расчет на JS)
7. 03 Преимущества — bento-сетка с гигантским «0» и GPS-виджетом
8. Лента клиентов «300+ компаний»
9. 04 Направления — крупные строки маршрутов + форма «свой маршрут»
10. 05 Этапы — контурные номера 01–05 с прогресс-линией
11. 06 Кейсы
12. 07 О компании
13. 08 Отзывы
14. 09 FAQ-аккордеон
15. 10 CTA-форма заявки
16. Футер с контурным вордмарком ШАРК ТРАНЗИТ

## Анимации (референсы — terminal-industries.com, elittrans62.ru)

- построчное появление заголовка hero через CSS-маски;
- появление блоков при скролле (IntersectionObserver);
- въезжающая фура с вращающимися колесами и «дорогой»;
- счетчики цифр, прогресс линии этапов, бегущие строки;
- параллакс фуры, hover-повороты стрелок в кружках, заливка строк;
- уважение `prefers-reduced-motion`.

## Файлы

- `index.html` — разметка (вся графика — инлайновый SVG, без внешних картинок)
- `css/style.css` — стили, брейкпоинты: 1180 / 1100 / 860 / 560 px
- `js/main.js` — прелоадер, меню, анимации, демо-калькулятор, формы

Формы и калькулятор работают в демо-режиме (без бэкенда): подмените
обработчики в `js/main.js` на реальные запросы при интеграции.
